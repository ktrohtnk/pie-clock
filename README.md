# Pie Clock (扇形スクリーンセーバー時計)

HTML5 CanvasとJavaScriptによる、針や数字を一切使わないミニマルな円形時計スクリーンセーバーです。

## 特徴
- **ミニマルデザイン**: 針や数字、目盛り、グラデーションや影を一切使わず、ソリッドカラーの面と幾何学的エッジのみで時間を表現。
- **時・分・秒の構成**:
  - 外周リング（または中心扇形）で秒の進行を描画
  - メインの円で分（長針）の進行度を扇形で描画
  - 時（短針）は指定位置のマーカーや扇形で表現
- **動的カラーパレット**: 1分ごと（0秒ジャスト）に色相の異なるビビッドカラー／コントラストカラーに一斉切り替え。
- **レスポンシブ対応**: 画面サイズや縦横向きの変更に自動追従。
- **フルスクリーン＆スリープ防止**: ダブルクリックでの全画面表示、Wake Lock APIによる画面消灯防止。

## 使い方
ブラウザで `index.html` を開くだけで動作します。
